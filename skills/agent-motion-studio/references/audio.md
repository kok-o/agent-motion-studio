# Local audio and scene preview

Scene preview uses the complete patched timeline's local mix, takes the selected scene's integer 48 kHz sample interval (`startFrame * 1600` through `endFrame * 1600`) and resets playback timestamps. It saves no draft. Music keeps its global loops, accents, gain, ducking and fades. Motion-scene file narration retains the existing 150 ms lead/tail and measured voice-length validation. Supplied caption times are ordered, non-overlapping integer milliseconds relative to the voice file; global frame rounding preserves cue order. This adds no transcription or video-scene narration/caption overlays.

Press Play explicitly to inspect sound; preview does not autoplay. With no enabled audio source there is no audio track. AAC samples are not byte-identical to pre-encoding PCM or a separately encoded full film. Decode/measurement checks do not establish human sound quality.

Active `audio.narration.provider:"edge"` with scene narration anywhere in the draft fails with `ONLINE_PREVIEW_UNSUPPORTED/preview/2` before provider or cache access. Do not strip accepted fields to bypass the guard. Use existing local file narration or separately authorized full export; preview adds no online provider calls.

Only v2 video scenes accept optional `sourceAudio:{enabled:true,gainDb:-12}`. Absence or `enabled:false` means Off. Gain defaults to 0 dB and must be between -60 and 0. A patch replaces the entire object, so include `enabled`; `null` removes it. Unrelated edits must leave an absent field absent.

Enabled source audio uses only the first stream. Its common timestamp clock is aligned to the actual first picture frame retained by native trim, resampled to 48 kHz stereo, cropped and placed at the scene's integer sample offset. Short or late audio is padded with silence, without loop or speed changes. Missing audio (`SOURCE_AUDIO_MISSING`), corrupt audio (`SOURCE_AUDIO_DECODE_FAILED`) or unsupported timestamps (`SOURCE_AUDIO_CLOCK_UNSUPPORTED`) fail before publication while On. Finite timestamps/time bases, constant-rate picture timing, readable packet continuity, decodable audio and bounded timestamp inspection are required. Variable/backward clocks are unsupported. Explicitly turn sound Off and rebuild preview to retain visual-only rendering.

Imports keep original source bytes. Source-video duration follows existing video import/trim limits (0–3600 seconds, at most512 MiB), not the separate600-second file-voice limit. Source replacement and generated acceptance preserve the current setting; restore returns it with the scene. A silent replacement while On needs an explicit Off edit and new exact preview. Keep the current ETag, original generated operation ID and receipt; use the existing [project/replay contract](manifest.md), never manual accepted JSON writes or automatic ordinary retries.
