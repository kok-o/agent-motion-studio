# Executable native styles

Use `styles --json` to read the installed calm-product, kinetic-poster and editorial v1 packages. Read the runtime's `docs/AUTHORING_STYLES.md` for exact fields and limits. A style changes layout/typography/motion of one native composition, preserving exact copy/facts/assets/order/duration/neighbors/brand/audio/history; it is not `video.style`, a fixed shot array or permission to invent claims. Follow the user's material and purpose, explicit source/brand constraints and separate human review.

For a new styled composition use a create request with fresh stable scene/object IDs, neutral `New text` or `Новый текст`, all groups and one headline role. For restyle, read `state`, use the existing IDs, explicitly choose groups and map every object to headline/body/proof/media/accent. Protect manual fields/objects; their provenance is not inferred. Keep existing tracks by default. Replacement requires `replaceTracks:true`; protected animated channels still take priority. A tracked base-field conflict requires revised locks or explicit replacement, not a blind retry.

`style-compile PROJECT --request REQUEST.json --if-match ETAG --out NEW_ACTION.json --json` returns a deterministic proposed ordinary action and audit without accepting it. `style-preview PROJECT --request REQUEST.json --if-match ETAG --out NEW_DIR --json` produces the exact action file, native MP4, audit and `projectHash`. Inspect that MP4 and `stale:false`, then use ordinary `edit PROJECT --action NEW_DIR/action.json --if-match PREVIEW_PROJECT_HASH --json`. Do not bypass the native writer. On conflict reread and explicitly preview again. On unknown/postcommit failure retain the submitted intent, read fresh state/history and do not blindly repeat the ordinary edit.

Styles support 1–5 text objects, at most one image/two existing accents, explicit roles, actual StudioSans400/700 fit, native bounds/holds/contrast. Editorial uses headline/body400 and proof700. No font download or glyph scaling through width tracks. Unsupported glyphs, overflow, short hold, unsafe bounds and lock conflicts are errors preserving copy and duration. Image-background contrast may be UNKNOWN; inspect it. Machine PASS is not artistic acceptance.

**Captions boundary:** restyle with existing composition captions is currently `STYLE_CAPABILITY`; preserve them. Ordinary object editing and E2 scene preview remain available. File narration without captions and music do not trigger this refusal. Active Edge narration still requires a full export for preview. Never disable captions automatically to obtain a passing style audit.

Studio has styled creation and selected-composition restyle with explicit groups/roles/protected fields, Preview/Cancel/Apply and read reconciliation. Any option/context change invalidates Apply; unknown outcomes never resend it. After acceptance verify an ordinary point edit, native restore and fresh-session reopen. Report technical results separately from human/artistic evaluation, which remains NOT RUN until a person actually evaluates the film.
