# DAILY RITUAL

A 20-second, four-scene espresso teaser using real, openly licensed camera footage and an original procedural score. [Credits and reuse terms](CREDITS.md).

Open `project.json` with `agent-motion-studio studio project.json`. Select scene 2 (`first-pour`), choose `first-drops.mp4`, then click **Предпросмотр сцены** to view the unsaved crop/trim. Click **Сохранить сцену** and **Экспорт MP4**. **Вернуть предыдущий вариант** restores the accepted scene, while keeping all five imported files.

Layout: 3-second motion title, 7-second wide extraction, 6-second detail, 4-second image/motion closing. `extraction-wide.mp4` is the original second scene; `first-drops.mp4` is the alternate. The included clips contain handles for changing trim. The detail shot is a documented crop from the same filmed setup.

Share `project.json`, `assets/`, `CREDITS.md`, `LICENSE.md`, `provenance.json` and this README. Runtime caches and exports are optional. Original source audio is muted; the film uses the supplied WAV. The local UI is currently in Russian; the English application README explains the button names and first remix.
