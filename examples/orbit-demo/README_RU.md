# ORBIT: редактируемый синтетический пример

Открытие: из корня Agent Motion Studio выполните `npm run studio`. Или `node dist/cli.js studio <путь>/project.json`. Проект содержит 20 секунд, четыре сцены и альтернативный Amber для второй сцены. Оригинальный Jade выбран после проверки возврата. Выберите второй кадр, смените исходник на amber.mp4, сохраните и экспортируйте. Возврат предыдущего варианта и история сохраняются в project.json.

Для переноса нужны project.json, assets, PROVENANCE.md и LICENSE. exports необязательны и содержат три готовых результата. Это оригинальные синтетические fixtures; художественное качество и спрос не подтверждаются техническими тестами. Полная инструкция: docs/STUDIO_RU.md в приложении.
