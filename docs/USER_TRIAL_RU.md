# Короткая независимая проверка

Статус: сценарий подготовлен, участник ещё не выполнял его. Собственный запуск разработчика/агента в новой папке — техническая проверка установки, а не опыт другого человека.

Участник, который не разрабатывал студию, получает только README, приложение и разрешённый переносимый проект. Дайте 20–30 минут, записывайте время и помощь; не подсказывайте заранее каждый шаг. API-вызовы, uploads и видеогенерация не нужны. Агент используется только в разрешённом участником официальном режиме; при API-оплате без бюджета пропустите модельный запуск и запишите ограничение. Приглашения автоматически не отправляются.

1. Установить по [README](../README.md) и [guide](GETTING_STARTED.md), выполнить doctor. Записать ОС, версии, exit code, отсутствующие tools и способ исправления.
2. Подключить skill, открыть новый официальный чат/сессию из рабочей папки. Записать, появился ли skill и прочитал ли его агент. Указать auth mode без токенов/ключей.
3. Открыть выданный существующий проект с assets/history. Подходит копия `coffee-ritual`; для продолжения ContextOS выдать готовый разрешённый ZIP. Не создавать фильм заново.
4. Самостоятельно выбрать одну правку второй сцены. Preview → просмотр → сохранение → экспорт. Записать время до первого preview/MP4, понимание source/preview/export и места, где потребовалась помощь.
5. Вернуть предыдущий вариант, экспортировать, закрыть и повторно открыть проект. Проверить сохранность источников, истории и остальных сцен.
6. Непрерывно посмотреть и прослушать экспорты. Отдельно записать читаемость/ритм/звук и желание сделать следующий фильм со своим материалом.

| Поле | Заполняет наблюдатель |
| --- | --- |
| Участник и дата | Псевдоним; новый пользователь или знакомый с проектом |
| Установка / doctor | Успех, команды/exit codes, препятствия |
| Клиент / skill / доступ | Версия, discovery, auth mode; NOT RUN с причиной |
| Первый preview / MP4 | Время, самостоятельность, помощь |
| Правка / restore / reopen | Что изменено, что сохранилось, сбои |
| Просмотр / звук | Конкретные замечания человека |
| Следующий материал | Что хочет сделать; это не доказательство оплаты/спроса |

Encode не заменяет просмотр человеком; подписка/ключ не заменяет разрешение на расходы. Не публикуйте личные материалы, prompts, session URLs или credentials. Исправляйте наблюдённые препятствия прежде расширения функций.
