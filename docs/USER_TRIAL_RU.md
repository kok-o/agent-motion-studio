# Короткая независимая проверка

Статус: комплект подготовлен; получен отдельный внешний технический отчёт агента на macOS arm64 от Олжаса. Независимая человеческая проверка удобства, просмотра и звука ещё не проведена. Поля результата ниже остаются пустыми: технический запуск не заполняет их за участника.

Комплект рассчитан на одного человека, который не разрабатывал студию. Основа программы — `main`, коммит `2d45a83a652ea317eeaffa34d4abd39fa909bd50` на 7 октября 2026; пример — принятый владельцем fastgrep, 18 секунд, 9:16, с музыкой. Его прежняя приёмка не является результатом этого участника. Новые функции и новый план не нужны.

Сохранённый ZIP исходников фиксирует эту базу и не содержит последующих локальных исправлений по внешнему отчёту. Для проверки исправлений используйте соответствующий новый checkout/runtime и запишите его commit/hash; старый комплект и пустой протокол сохраняются. [Текущее техническое состояние](STATUS.md).

## Установка из main

Распакуйте комплект в новую папку. Откройте PowerShell там, где находятся `START_HERE_RU.md` и оба ZIP. Команды ниже предназначены для Windows. Установите Node.js ≥22.12, Chrome/Chromium и FFmpeg/ffprobe с libx264/AAC по [существующей инструкции установки](GETTING_STARTED.md). FFmpeg и ffprobe должны быть на PATH. После установки инструментов откройте терминал заново. Git нужен только для клонирования; он не нужен для установки из выданного ZIP.

Выберите один способ получения исходников. При доступе к GitHub:

```powershell
git clone --branch main --single-branch https://github.com/kok-o/agent-motion-studio.git
Set-Location .\agent-motion-studio
git rev-parse HEAD
```

При уже настроенном SSH-доступе замените только clone-команду на `git clone --branch main --single-branch git@github.com:kok-o/agent-motion-studio.git`. HTTPS/SSH используют разные способы аутентификации; ошибка чтения Username в безынтерактивном окружении не доказывает отсутствие SSH-доступа. [Варианты и диагностика](GETTING_STARTED.md#get-the-source-choose-one-route). Если доступа нет, используйте выданный ZIP; ключи/токены в URL и отчёт не вставляйте.

Без доступа к репозиторию, из архива того же main:

```powershell
Expand-Archive -LiteralPath .\agent-motion-studio-main-2d45a83.zip -DestinationPath .
Set-Location .\agent-motion-studio
```

Затем, из папки `agent-motion-studio`:

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run build
node dist/cli.js doctor --json
```

Продолжайте, когда doctor возвращает `ready:true`, exit 0. При exit 3 исправьте указанную зависимость по подсказке doctor и повторите команду. `npm.cmd` обходит блокировку npm.ps1 без изменения execution policy. Установка скачивает npm-зависимости; видеопровайдер и ключ генерации для неё не нужны. Для этого сценария запускать maintainer tests или готовить release не требуется.

### macOS: установка из Terminal

Сначала установите недостающие системные инструменты и задайте `CHROME_PATH` по [macOS-разделу](GETTING_STARTED.md#macos-tools-terminal-zshbash) в этом же Terminal. Используйте Chrome/Chromium/Edge для рендера; привычный браузер может показывать UI. Выберите один способ получения исходников из папки комплекта:

```sh
git clone --branch main --single-branch https://github.com/kok-o/agent-motion-studio.git
```

Или с существующим SSH-доступом:

```sh
git clone --branch main --single-branch git@github.com:kok-o/agent-motion-studio.git
```

Или из выданного ZIP в новую папку:

```sh
unzip -n agent-motion-studio-main-2d45a83.zip
```

После выбранного варианта:

```sh
cd agent-motion-studio
npm ci --ignore-scripts
npm run build
node dist/cli.js doctor --json
node scripts/install-agent-skill.mjs --client codex --scope project
```

Продолжайте при `ready:true`; для Claude Code замените `codex` на `claude`. Запишите ОС, commit, версии инструментов и команды. Внешний технический запуск macOS описан отдельно; обновлённая последовательность и исправления пока не исполнены на macOS самим разработчиком. На Linux следуйте source-инструкции и установке системных инструментов своей ОС.

## Подключение skill

В той же папке, для Codex:

```powershell
node scripts/install-agent-skill.mjs --client codex --scope project
```

Для Claude Code используйте вместо неё:

```powershell
node scripts/install-agent-skill.mjs --client claude --scope project
```

Установщик копирует весь skill с references, работает offline и сохраняет login/settings клиента. Codex получает `.agents/skills/agent-motion-studio/SKILL.md`, Claude Code — `.claude/skills/agent-motion-studio/SKILL.md`. Если существующий skill отличается, установщик сохраняет его и сообщает о конфликте; сначала сделайте резервную копию за пределами каталога skills.

Откройте новый официальный чат/сессию агента в папке `agent-motion-studio`. В Codex используйте `$agent-motion-studio`, в Claude Code — `/agent-motion-studio`; при необходимости перезапустите клиент для discovery. Запишите, виден ли skill, прочитан ли он агентом и вызывает ли агент CLI. Установка файлов сама по себе этого не подтверждает. Оставьте текущее официальное подключение клиента; auth mode запишите без ключей/токенов. Если запуск использует оплачиваемый API и бюджет не разрешён, пропустите модельный запуск и отметьте ограничение.

## Открытие готового fastgrep

Сначала посмотрите и прослушайте выданный `fastgrep-sound-revised.mp4` в обычном плеере. Затем из папки `agent-motion-studio` распакуйте проект один раз в новую личную папку:

```powershell
New-Item -ItemType Directory -Path .\projects\trial-fastgrep
Expand-Archive -LiteralPath ..\fastgrep-sound-revised-project.zip -DestinationPath .\projects\trial-fastgrep
node dist/cli.js studio .\projects\trial-fastgrep\fastgrep-project\project.json
```

На macOS, из папки `agent-motion-studio`, вместо этих PowerShell-команд:

```sh
mkdir -p projects/trial-fastgrep
unzip -n ../fastgrep-sound-revised-project.zip -d projects/trial-fastgrep
node dist/cli.js studio projects/trial-fastgrep/fastgrep-project/project.json
```

Распаковка нужна один раз; существующую копию открывайте только последней командой. Сохраните весь каталог `fastgrep-project`, включая assets/sources/history.

Откройте полную session URL, напечатанную CLI, и оставьте этот терминал работать. Ссылка приватная и меняется при перезапуске. Если порт занят, добавьте `--port 4174`. В студии выберите RU. Главный плеер показывает экспорты этой копии; готовый исходный MP4 выдан отдельным файлом. Preview сцены без звука; звук оценивается в полном MP4.

Студия работает как локальный Node-процесс на `127.0.0.1`; держите его терминал открытым, а правки агента выполняйте из другого терминала/клиента в той же рабочей папке. Validate/preview/render также запускают временный loopback-сервер, изолированный headless-браузер и FFmpeg/ffprobe. Агенту нужны разрешения на эти локальные процессы, loopback и запись проекта/экспорта. `EPERM listen` в read-only sandbox проверяйте как ограничение среды: используйте штатное разрешение команд в клиенте или локальный Terminal, сохраняя sandbox браузера. [Подробности](GETTING_STARTED.md#local-processes-and-loopback).

Если инструментам не хватает памяти, используйте существующий режим `$env:AMS_LOW_MEMORY = '1'` в терминале перед doctor/studio/render и запишите его применение. Рендеры выполняйте по одному. При общении через desktop-клиент попросите агента использовать этот режим для своих CLI-рендеров.

На macOS/Linux тот же режим задаётся `export AMS_LOW_MEMORY=1`. Пути инструментов и этот режим должны быть доступны и CLI-процессам агента. Обычный полный экспорт `render ... --out NEW_DIRECTORY` сохраняет студийную копию в проекте; в исправленном runtime она появляется в списке открытой студии автоматически, сохраняя черновик. Preview не считается полным экспортом. Остановка Ctrl+C завершает сервер и сообщает, был ли отменён активный рендер.

Для знакомства агента с готовым проектом передайте сообщение с подключённым skill:

```text
Продолжи projects/trial-fastgrep/fastgrep-project/project.json.
Прочитай state и историю. Сохрани текущую manifest.revision как
исходную ревизию этого теста для последующего восстановления.
Пока только ознакомься с готовым проектом. Сохраняй источники и историю.
Используй локальные операции студии; без дополнительных платных вызовов,
видеопровайдеров, uploads и публикации.
```

Для повторного открытия позже нужна только команда:

```powershell
node dist/cli.js studio .\projects\trial-fastgrep\fastgrep-project\project.json
```

`new`/`init` и повторная распаковка для продолжения не нужны. Копия лежит в игнорируемой папке `projects/`; исходный ZIP остаётся отдельно.

## Действия участника

Дайте 20–30 минут на первое прохождение; если установка заняла дольше, запишите это отдельно. Наблюдатель фиксирует время и оказанную помощь, не выбирая правку за участника. Порядок сохраняет существующий сценарий проверки:

1. Установить студию и выполнить doctor. Записать ОС, версии Node/Chrome/FFmpeg/ffprobe, источник программы/commit, exit code, отсутствующие tools и исправления.
2. Подключить skill и открыть новую официальную сессию из рабочей папки. Зафиксировать discovery, чтение skill, реальные CLI-вызовы и auth mode без credentials.
3. Открыть выданный проект с assets/history. Зафиксировать `manifest.revision` начала этого теста. Просмотреть исходный MP4.
4. Самостоятельно выбрать одну правку второй сцены и описать её своими словами. Агент читает актуальное state → делает preview без записи → участник смотрит preview → после принятия применяет ту же правку → экспортирует в новую папку. Записать время до первого preview/MP4, что изменилось и где потребовалась помощь. В composition положение и текст объектов редактируются через агента/API/CLI; realtime object editor в браузере отсутствует.
5. Попросить агента вернуть через историю именно ревизию начала этого теста, экспортировать в ещё одну новую папку, закрыть студию и повторно открыть проект. Проверить сохранность источников, истории и остальных сцен. Вложенные старые restore action-файлы относятся к истории владельца: цель нового восстановления — записанная ревизия участника.
6. Непрерывно посмотреть и прослушать исходный, изменённый и восстановленный MP4. Отдельно записать читаемость, ритм, звук и желание сделать следующий фильм со своим материалом.

Для правки можно передать агенту сообщение, заполнив только собственную просьбу:

```text
В projects/trial-fastgrep/fastgrep-project/project.json измени вторую сцену:
[моя правка]. Прочитай актуальное состояние, сохрани исходную ревизию теста.
Сначала сделай preview без записи и покажи мне его. После моего принятия
сохрани эту правку штатным edit и экспортируй MP4 в новую папку.
Сохрани остальные сцены, исходники, предыдущие экспорты и историю.
```

Если часть сценария недоступна, участник/наблюдатель записывает NOT RUN и причину в соответствующее поле. Ручная работа через UI может проверить редактор, но не заменяет подключение агента. Программа, инструкции и прошлые проверки не считаются результатом нового пользователя.
