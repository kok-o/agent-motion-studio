# Visual design and review

The `kinetic` style supplies local Oswald display typography, authored line breaks, image reveals, focal crops, motion accents and procedural music. The original `studio` style remains available for existing projects. Templates are a starting point; successful encoding alone does not make an effective film.

For v1 kinetic scenes, transitions retain the outgoing image while revealing the next composition. v2 mixed-media projects use hard cuts. Cover uses a crop/focal point; contain retains the full image. Narration captions and CTA labels reserve separate regions.

When changing a visual recipe, check settled frames and scene boundaries in both aspect ratios, short scenes, Latin/Cyrillic text and the actual full film. Listen to the exported audio separately from numerical signal checks. Avoid claiming quality parity or improved filmmaking without comparing real results and collecting human judgments.

Run `npm run test:integration` for frame-order, boundary, short-scene, crop and caption behavior. The [coffee example](../examples/coffee-ritual/README.md) demonstrates real footage with titles; earlier synthetic drawings are explicitly labelled fixtures. Keep the [media credits](../examples/coffee-ritual/CREDITS.md) when sharing the coffee remix.
