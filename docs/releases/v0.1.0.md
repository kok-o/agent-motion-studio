# Agent Motion Studio 0.1.0 — experimental developer preview

Import your clips, images and music, assemble a short storyboard, preview a scene, replace a take and export MP4. The browser and CLI share a portable project with history, so people and agents can work on the same film.

This first release includes a 20-second DAILY RITUAL example and an alternative second scene. You can try the whole local editing flow without a model key. Cloud video generation is planned, not included.

## Downloads and first run

- `agent-motion-studio-0.1.0-source.zip`: source code, contributor files, fixtures and demos. Install dependencies and build using the README.
- `agent-motion-studio-0.1.0.tgz`: built CLI/editor for local npm installation; no source build needed.
- `coffee-ritual-project.zip`: portable editable example with its sources and credits.
- `SHA256SUMS.txt`: checksums for the three archives.

Node ≥22.12, Chrome/Chromium and FFmpeg/ffprobe are required separately. [Setup and first remix](../../README.md#try-your-first-remix) · [Compatibility](../COMPATIBILITY.md).

## Included

Video/image/music import; storyboard; trim/crop/focal point; silent draft previews; explicit external-edit conflict resolution; previous-take restoration; real H.264/AAC MP4; v1 compatibility; scripts for preparing and checking a local release.

## Known limits

Russian UI, on-demand silent previews, full-film viewing after export, muted source-video audio, hard cuts in v2, 1080p/30 fps and SDR. No realtime multitrack timeline, built-in chat, cloud video provider or automatic system dependency installer. Other computers and first-time users still need testing. See the README for input limits.
