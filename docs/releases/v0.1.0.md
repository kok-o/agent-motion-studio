# Agent Motion Studio 0.1.0 — experimental developer preview

Import your clips, images and music, assemble a short storyboard, preview a scene, replace a take and export MP4. The browser and CLI share a portable project with history, so people and agents can work on the same film.

This pre-release includes the 20-second DAILY RITUAL example, an alternative second scene, and a [37-second recording of the real CLI/Studio workflow](../LAUNCH_DEMO.md). Local editing/rendering needs no video-model key. Your external agent's subscription/API costs are separate. An optional Replicate Wan replacement-take adapter is implemented and tested offline; live provider/billing/output verification is NOT RUN.

## Downloads and first run

- `agent-motion-studio-0.1.0-source.zip`: source code, contributor files, fixtures and demos. Install dependencies and build using the README.
- `agent-motion-studio-0.1.0.tgz`: built CLI/editor for local npm installation; no source build needed.
- `coffee-ritual-project.zip`: portable editable example with its sources and credits.
- `agent-motion-studio-first-user-0.1.0-8e5106ad2a18.zip`: unchanged, checksum-pinned first-human kit with local instructions. Its clean `8e5106a` source stamp and SELF_RUN are older build snapshots, not the release commit; [identity and hashes](../USER_TRIAL_RU.md).
- `launch-demo-project.zip`: original procedural demo project with source/history and permitted example takes.
- `agent-motion-studio-demo.mp4` and `social-preview.png`: real recorded demonstration and cover; [credits and recording limits](../LAUNCH_DEMO.md).
- `SHA256SUMS.txt`: hashes of the actual attached distributable files. Newly built source/runtime archives are separate from the preserved first-human kit.

Node ≥22.12, Chrome/Chromium/Edge and FFmpeg/ffprobe are required separately. Start with the first-human kit's local `START_HERE_RU.md`; no source checkout/build is needed for that route. [Source checkout setup](../../README.md#try-your-first-remix) · [Compatibility](../COMPATIBILITY.md).

## Included

Video/image/music import; storyboard; trim/crop/focal point; silent unsaved previews; explicit external-edit conflict resolution; previous-take restoration; real H.264/AAC MP4; v1/v2 compatibility; RU/EN labels; brand palettes; editable object compositions; agent batch/preview workflows; CLI exports in the editor; bounded Windows export promotion; and failure context in verification tools.

## Known limits

On-demand silent previews, full-film viewing after export, muted source-video audio, hard cuts in v2, 1080p/30 fps and SDR. No realtime multitrack timeline, built-in chat, local video-model inference or automatic system dependency installer. Agent accounts/subscriptions remain external; installing a skill is not a successful model session. Windows/Linux CI and external installed macOS evidence have their documented scopes, not universal OS support.

Independent human viewing/listening/usability and clean-OS setup remain **NOT RUN**. Historical natural Windows EPERM and installed-kit reopen timeout causes remain **UNKNOWN**; additional diagnostics and later GREEN do not establish a runtime fix. This is not a stable release.
