# Исторические документы

Эта папка сохраняет решения и первоначальные спецификации. Текст не является актуальным статусом или поручением, даже если внутри написано «следующая задача». Цены, условия внешних сервисов и старые команды требуют отдельной проверки перед использованием.

Рабочий документ один: [PLAN_V0.2_RU.md](../PLAN_V0.2_RU.md). Факты находятся в [STATUS.md](../STATUS.md).

| Документ | Зачем сохранён |
| --- | --- |
| [DEVELOPMENT_PLAN_RU.md](2026-10/DEVELOPMENT_PLAN_RU.md) | Полная старая спецификация; особенно полезны контракты generation/jobs/accept и матрицы ошибок. Это не карта покрытия текущих тестов |
| [AGENT_START_PROMPT_RU.md](2026-10/AGENT_START_PROMPT_RU.md) | Предыдущее поручение A1/P2 |
| [AGENT_SETUP.md](2026-10/AGENT_SETUP.md) | Исследование discovery разных клиентов от 5 октября, не подтверждение их текущей поддержки |
| [QUICKSTART.md](2026-10/QUICKSTART.md) | Старый путь v1 manifest; для актуального редактора использовать GETTING_STARTED и AGENT_WORKFLOW |

На старых публичных путях оставлены только указатели для существующих ссылок. Локальные личные брифы и отчёты, ранее исключённые из Git, не добавляются в публичный архив.
