# Протокол нового пользователя

Заполняет реальный участник или наблюдатель после действий. Все поля ниже оставлены пустыми. Технический self-run комплекта записывается отдельно и не заполняет результат человека.

| Поле | Результат участника |
| --- | --- |
| Участник (псевдоним), дата, участвовал ли в разработке | |
| Git SHA, source.dirty, версия, хеш ZIP/runtime | |
| ОС, версии Node/Chrome/FFmpeg/ffprobe, low memory | |
| Установка и doctor: время, exit code, помощь | |
| Официальный клиент/версия, auth mode без secrets | |
| Discovery/чтение skill и фактические CLI-вызовы | |
| Открытие coffee и исходная revision этого теста | |
| Собственная просьба о правке | |
| Preview: время, просмотр, принятие, помощь | |
| Edit/export: совпадение с просьбой и отдельный MP4 | |
| Restore/reopen: источники, credits, история, прежние MP4 | |
| Непрерывный просмотр/слух: замечания человека | |
| Удобство и желание продолжить со своим материалом | |
| Что не проверено и почему; итог участника | |

Не включайте credentials, prompts с личными данными или приватные session URLs. Отсутствующий клиент/бюджет/просмотр отмечается NOT RUN с причиной после фактического прохождения; агент не придумывает ответы за человека.
